# 제주 옷차림 비서

제주의 날씨에 맞는 **오늘·내일·이번주·다음주 옷차림**을 추천해 주고, 내가 입은 옷 사진을 날씨와 함께 기록해서 **비슷한 날 내가 입었던 옷**을 다시 보여 주는 웹앱입니다. 컴퓨터와 폰 화면 모두에서 쓸 수 있습니다.

> 기술: Vite + React + React Router + Zustand + Bootstrap(Bootswatch minty) / Supabase(로그인·사진·기록) / Claude(AI 도우미) / Vercel 배포

---

## 주요 기능

### 1. 날씨와 옷차림 추천 (홈)
| 기능 | 설명 |
|---|---|
| **지역 선택** | "내 위치", 제주시, 서귀포시 중 고르고, 제주시·서귀포시는 동·읍·면까지 고를 수 있어요 (제주시 26곳, 서귀포시 17곳, 가나다순). 고른 뒤 **날씨 보기**를 눌러야 불러와요. |
| **마지막 지역 기억** | 마지막으로 본 지역을 기억해서, 다음에 열면 자동으로 그 지역 날씨를 보여 줘요. |
| **오늘** | 지금 기온과 앞으로 12시간의 시간별 예보(옆으로 밀어서 보기), 추천 옷차림 |
| **내일** | 내일 최고/최저 기온과 24시간 시간별 예보, 추천 옷차림. 전날 미리 옷을 챙기는 분들을 위한 탭이에요. |
| **이번주 · 다음주** | 날짜별로 [날씨 카드 + 추천 옷차림 카드]와 한 주 요약. 월~일 기준이고, 기상청 예보는 최대 10일 뒤까지라 다음주는 일부만 보일 수 있어요. |
| **추천 옷차림 카드** | 기온 구간(매우 더움 ~ 매우 추움)별 설명, 옷 그림 카드, 비·눈·강한 바람·큰 일교차 팁 |

**옷차림 추천 기준** (`src/lib/outfit.js`에서 숫자·옷을 바꿀 수 있어요)

| 구간 | 기온 | 대표 옷 |
|---|---|---|
| 매우 더움 | 28℃ 이상 | 민소매, 반팔, 반바지, 린넨 옷 |
| 더움 | 23~27℃ | 얇은 셔츠, 반팔, 반바지, 면바지 |
| 따뜻함 | 20~22℃ | 얇은 가디건, 긴팔 티, 면바지, 청바지 |
| 선선함 | 17~19℃ | 가디건, 얇은 니트, 맨투맨, 청바지 |
| 쌀쌀함 | 12~16℃ | 자켓, 가디건, 야상, 니트, 청바지 |
| 추움 | 9~11℃ | 트렌치코트, 자켓, 니트, 기모 바지 |
| 꽤 추움 | 5~8℃ | 코트, 가죽 자켓, 니트, 히트텍, 기모 바지 |
| 매우 추움 | 4℃ 이하 | 패딩, 두꺼운 코트, 목도리, 장갑, 두꺼운 니트, 히트텍, 기모 바지 |

- 오늘 탭은 **지금 기온** 기준(바람이 센 날은 2℃ 낮춰서), 내일·이번주·다음주는 **하루 최고와 최저의 중간값** 기준이에요.
- 비가 오면 우산, 더운 날은 모자를 더하고, 17~27℃에서 바람이 센 날은 바람막이를 추천해요.
- 카드는 소품 → 아우터 → 상의 → 바지 순서로 보여 줘요. 이모지가 없는 옷은 직접 그린 그림을 써요.

### 2. 날씨별 옷차림 (메뉴 "날씨별 옷차림")
기온에 따라 어떤 옷을 추천하는지 **더움에서 추움까지 세로로 이어서** 한눈에 볼 수 있어요. 비 오는 날 / 바람 센 날 / 일교차 큰 날 스위치로 추천이 어떻게 달라지는지도 볼 수 있어요.

### 3. AI 도우미 (메뉴 "AI 도우미")
Claude에게 제주 옷차림에 대해 자유롭게 물어볼 수 있어요. 비밀 키는 서버(`/api/agent`)에서만 써요.

### 4. 로그인 (오른쪽 위 "로그인")
- 이메일 + 비밀번호로 가입·로그인 (Supabase Auth)
- 로그인하면 **오늘 입은 옷 사진 기록, 비슷한 날 추천, 마이페이지**를 쓸 수 있어요.
- 가입 확인 메일이 켜져 있으면 메일의 링크를 누른 뒤 로그인해야 해요.

### 5. 오늘 입은 옷 기록 (홈 오늘 탭, 로그인 필요)
- **사진 올리기**: 하루에 한 장. 긴 변 1280px로 줄여서 올려요. 같은 날 다시 올리면 바뀌고, 지울 수도 있어요.
- **날씨 함께 저장**: 최고/최저 기온, 하늘 상태, 비·눈, 바람, 오전/오후 요약, 기온 구간, 지역
- **오늘 옷, 입어 보니 어땠나요?** 5단계 중 하나를 고르는 칸 (안 골라도 돼요)
  `많이 더웠어요 · 조금 더웠어요 · 딱 좋았어요 · 조금 추웠어요 · 많이 추웠어요`
- **한 줄 후기**: 예) "안에 반팔이 아니라 긴팔을 입었으면 딱 좋았을 듯" (최대 200자, 안 써도 돼요)
- 사진은 **비공개**로 저장되어 나만 볼 수 있어요.

### 6. 비슷한 날, 내가 입었던 옷 (홈 오늘·내일 탭, 로그인 필요)
오늘(또는 내일) 날씨와 **비슷했던 날 내가 입은 옷 사진**을 보여 줘요.

| 항목 | 내용 |
|---|---|
| **비교 방법** | 오늘의 최고는 과거의 최고와, 최저는 과거의 최저와 비교해요. 카드에 `과거 / 오늘 / 차이` 세 줄로 보여 줘요 (차이는 오늘 − 과거, `+`는 빨강·`-`는 초록 계열). |
| **순서** | ① 그때의 느낌이 **딱 좋았어요**인 옷 먼저 → 조금 더웠/추웠어요 → 많이 더웠/추웠어요 → 느낌 없음 ② 같은 느낌끼리는 날씨가 더 비슷한 순서 ③ 같으면 최근 기록이 먼저 |
| **걸러내는 기록** | 그날 추웠는데 오늘이 더 춥거나, 그날 더웠는데 오늘이 더 더운 기록 / 기온 차이가 평균 4℃, 한쪽이라도 6℃ 넘는 기록 |
| **슬라이드와 더보기** | 홈에서는 최대 5개를 옆으로 밀어서 보고, 더 있으면 **더보기**로 최대 30개를 모아 보는 페이지(`/similar`)로 이동해요. |
| **자세히 보기** | 카드를 누르면 큰 사진, 그날 날씨, 느낌, 후기가 나와요. |

(기준과 숫자는 `src/lib/pastOutfits.js`에서 바꿀 수 있어요.)

### 7. 마이페이지 (로그인하면 오른쪽 위에 생김)
- **달력 보기**: 연도·월을 골라 그 달로 이동해요. 사진을 올린 날은 사진 칸에 날씨 아이콘과 느낌 색 점이 보이고, 누르면 자세히 볼 수 있어요.
- **목록 보기**: 연도별로 묶어서 사진·날씨·느낌·후기를 카드로 보여 줘요.
- **지난 날짜에 사진 올리기**: 사진이 없는 날(오늘 포함)을 누르면 그날의 사진을 올릴 수 있어요. 앞으로 올 날짜는 막혀 있어요.
  - 지난 날짜는 **그날 있던 지역**을 고르면, 가까운 관측소(제주·고산·성산·서귀포)가 잰 **그날의 관측 날씨**가 자동으로 함께 저장돼요. (관측 자료는 어제까지 제공돼요.)
- 느낌과 후기는 나중에도 고칠 수 있고, 사진은 지울 수 있어요.

### 8. 폰 화면 (반응형)
- 상단 메뉴는 폰에서 햄버거 버튼으로 접혀요.
- 달력은 화면 가로를 꽉 채우고, 느낌 버튼은 `더웠어요 두 개 / 딱 좋았어요(한 줄 전체) / 추웠어요 두 개`로 놓여요.
- 시간별 예보와 비슷한 날 카드는 옆으로 밀어서 보고, 사진 창은 폰에서 전체 화면으로 열려요.

## 실행

```bash
npm install
copy .env.example .env.local     # Mac/Linux: cp .env.example .env.local  → 값 채우기
npm run dev                      # 화면 + /api 서버 함수 (http://localhost:5173)
```

`npm run dev` 하나로 화면과 `/api`(서버 함수)가 같이 실행돼서 `vercel dev`가 필요 없어요.

### 환경변수 (`.env.local`)

| 이름 | 설명 |
|---|---|
| `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` | Supabase 연결 (브라우저에 공개돼도 되는 값) |
| `DATA_GO_KR_KEY` | 공공데이터포털 **일반 인증키(Decoding)** — 서버에서만 사용 |
| `ANTHROPIC_API_KEY` | Claude 키 — 서버에서만 사용 |

> `VITE_`로 시작하지 않는 값은 브라우저에 들어가지 않아요. `.env.local`은 git에 올라가지 않아요.

### Supabase 준비 (로그인·사진 기록을 쓰려면)
1. Supabase 프로젝트를 만들고 위 두 값을 `.env.local`에 넣어요.
2. 대시보드 → **SQL Editor** → New query에 `supabase/schema.sql` 내용을 붙여넣고 **Run**해요. (여러 번 실행해도 안전해요. 기능이 추가될 때 다시 실행하면 칸이 더해져요.)
   - 기록 테이블 `outfit_logs`(사진 경로·날씨·느낌·후기), 비공개 사진 보관함 `outfit-photos`, 내 것만 볼 수 있는 보안 규칙(RLS)이 만들어져요.
3. Authentication 설정에서 가입 확인 메일 사용 여부를 정하고, 배포하면 **Site URL**을 배포 주소로 바꿔요.

### 배포 (Vercel)
1. GitHub에 올리고 Vercel에서 프로젝트를 가져와요.
2. Vercel **Environment Variables**에 위 값들을 모두 넣고 다시 배포해요. (`VITE_` 값은 빌드할 때 들어가므로 바꾸면 다시 배포해야 해요.)
3. `vercel.json`: 서울 리전(icn1), `/api`를 뺀 주소는 모두 `index.html`로 보내요(새로고침해도 페이지가 열려요).
